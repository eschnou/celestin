## Deviations

1. **Assistant seed items use `output_text`** (design §3.6 said `text`). The Realtime API rejected `text` with `Invalid value: 'text'. Value must be 'output_text'` on the first real session; fixed in `VoiceService._to_realtime_item` and its test.
2. **`voice_probe.py` is a separate script**, not a mode of `probe.py` (task 4.10), and runs the text model as a proxy. Its third answer still wrote `$q$`; the live Realtime session phrased maths in words. Left as a cheap regression check on the block's wording rather than iterated further.
3. **No `reasoning` retry in the Realtime adapter** (design §3.2/§3.7 described a retry without `reasoning` on a 400). Removed in the simplify pass: whether a model accepts `reasoning` is a configuration fact, and `VOICE_REASONING_EFFORT=""` omits the field. The default model accepted it in every real run.
4. **The "working" phase is set as soon as a tool call is queued**, not when the request leaves (design §3.12 was silent on the exact moment); it makes the header honest during the microtask before the fetch starts.
5. **Interruption keeps the transcript received so far** (design decision 6, restating requirement R4.4's deviation): no `audio_end_ms` trimming.
6. **Real barge-in and the empty-transcript opening by voice were not exercised live**: the browser checks ran with a synthetic silent microphone and the page's text opening turn always precedes the mic click. Both paths are covered by unit tests and fixtures (`cancelled`, `late_interruption`, `opening: true`).
