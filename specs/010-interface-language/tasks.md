# 010 — Tasks

Phases are testable increments in dependency order. Each ends with a check the user can run. Requirement ids (`R1`…) refer to `requirements.md`, section numbers (`§`) to `design.md`. Tick tasks as they land; record design deviations in the Deviations section at the end.

Work on `feature/interface-language`, merged in one go: the epic touches most frontend files, and the branch must never be half-translated.

Checks for every phase that touches a side: backend `uv run pytest`; frontend `npm run typecheck` (added in 0.4), `npm run lint`, `npm test` (which runs `i18n` and `i18n:check` first).

The load-bearing constraint across the whole epic: **French does not move.** No existing test assertion on French text changes (the only edits to existing tests are the accessor renames named in 3.5 and the reason codes in 3.3), no golden in `backend/tests/fixtures/render/` is regenerated, and no function the model reads gains a locale parameter (§4.7). Where a task replaces French literals, capture them first (3.1, 4.2, 4.3) so the French rendering is asserted against what the code said before.
